Netflix Clone using React

## Getting Started

```bash
create .env.local

API_KEY=
SECRET_KEY=
TESTID_KEY=
TESTPD_KEY=
```

```bash
pnpm i
# and
pnpm dev
```

## Details

### Frontend

```bash
• React / Typescript
• React Router
• Tanstack (React Query)
• Redux Toolkit
• React Modal
• React Hook Form
• React Responsive
• Tailwind CSS
• Vite
```
